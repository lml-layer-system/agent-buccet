# Code of Conduct

## Our Standards

Agent Buccet is a technical project focused on AI agent containment and enforcement. Participation should be focused, constructive, and professional.

**Expected:**
- Technical rigor — proposals and critiques grounded in specifics
- Honesty about tradeoffs, limits, and uncertainty
- Respect for other contributors' time and work
- Clear, direct communication

**Not acceptable:**
- Harassment, personal attacks, or discriminatory language
- Bad-faith contributions designed to weaken the security boundary
- Deliberate misinformation about what Agent Buccet does or does not protect

## Enforcement

Violations should be reported to the maintainers via GitHub Security Advisories (for security-related conduct) or by opening a private issue. Maintainers will review and respond within 7 days.

Consequences range from a request to edit/remove content, to temporary or permanent exclusion from the project, depending on severity and pattern of behavior.

## Scope

This Code of Conduct applies within all project spaces: GitHub issues, pull requests, discussions, and any official communication channels related to Agent Buccet.
