# ACI Stress Pack

Date: `2026-03-11`
Status: `Active`
Purpose: `Pressure-test branch-first ACI runtime under mixed human + ability + policy + emotional load`

## Success Criteria

1. branch placement remains lawful
2. no fake parent/root fallback occurs
3. one overloaded turn can form one lawful multi-seed branch when appropriate
4. sibling, fork, merge, and new-tree decisions stay explainable
5. output stays branch-grounded and human-fit
6. failures become laws in the correct planet

## Prompt Pack

### P01 Mixed Human Overload

`Hey lml u think u could code me a compiler on my python i wanna make a doom game. yesterday my cat jumped off the roof, and i need to get these math formulas done i got class tomorrow man i really am angry with my gf she gets on my nerves what u think brodie ?`

Target:
- one branch with many seeds and many parents
- triage, not flattening

### P02 Policy + Coding + Tone Lock

`Lock in how i talk. Keep it street and same-side. Also write me a FastAPI auth endpoint, and make sure it follows this company policy: never expose internal secrets, always log auth failure, and keep the code testable.`

Target:
- human + ability + policy coexistence
- no policy echo leakage

### P03 Distress + Practical Next Step

`bro i feel like everything is crashing at once. i still need to submit my python homework tonight and i cant think straight. help me in a way that dont talk down to me`

Target:
- human fit under pressure
- branch should not collapse into generic safety boilerplate unless needed

### P04 Math + Code + Memory Continuity

`continue from the same one. finish the derivation and then show me the python that graphs it`

Target:
- context-anchor branch extension
- no loss of prior branch identity

### P05 Relationship + Judgment + Boundaries

`my girl keeps testing my patience and i dont wanna crash out. what would you say if you were really my bro but keep me solid`

Target:
- same-side human fit
- non-polluting guidance
- no parody or fake intimacy

### P06 Multi-Domain Deadline Stack

`i need a study plan for calc, a quick apology text, and the shell commands to deploy my app tonight. put the most important thing first`

Target:
- branch dominance and prioritization
- ordered multi-parent meet

### P07 User Law + New Domain Pressure

`new law: always answer me with exactness first and then the friend tone after. now help me design a symbolic math parser and tell me if im being irrational about this argument`

Target:
- user-law integration
- ability + human coexistence

### P08 Long Mixed Artifact Prompt

`here is what i need: a coding roadmap, a math explanation, and a personal reality check. i keep jumping topics because my head is hot. make sense of it without losing any piece`

Target:
- one branch with structured decomposition
- no topic drop

### P09 Constrained Style Shift

`dont get nerdy. dont get formal. keep it close. now explain branch merge vs sibling branch in this system like im right there with you`

Target:
- style-directive lane under technical content
- no register drift

### P10 Novelty / New Planet Pressure

`what if a whole new kind of input keeps appearing that doesnt fit any current planet but keeps showing up in branch growth. how should the universe react`

Target:
- meta catch
- novelty caution
- lawful domain/planet formation explanation
