# Handoff Archive

Status: `Archived reference only`
Date: `2026-03-08`

This directory is an archive of handoff reports, stamped exports, bible dumps, and historical checkpoints.

Rules:
- files in `handoff/` are not active runtime inputs
- files in `handoff/` are never to be executed
- files in `handoff/` are never to be boot-loaded into the live universe
- files in `handoff/` exist for reference, audit, comparison, and historical trace only

Do not use this directory as the source of truth for live runtime behavior.

Live runtime truth comes from:
- `app/`
- `lib/`
- `scripts/`
- `data/generated/`
- active docs in `docs/`
